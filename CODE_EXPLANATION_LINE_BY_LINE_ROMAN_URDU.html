Hissa C: Shannon Entropy Function (Lines 25 to 30)

def calculate_entropy(text: str) -> float:
    if not text:
        return 0.0
    length = len(text)
    counts = Counter(text)
    return -sum((c / length) * math.log2(c / length) for c in counts.values())

Is Function Ka Kaam: Yeh function URL ke andar text ki Randomness (Be-tarteebi) calculate karta hai.

  • if not text: return 0.0: Agar string khali ho to entropy 0 return karo.
  • length = len(text): URL ke kul characters ki ginti.
  • counts = Counter(text): Har character kitni baar aaya (e.g. 'a' kitni baar, '1' kitni baar).
  • return -sum(...): Mathematical Shannon Entropy formula: $$H(X) = -\sum P(x) \log_2 P(x)$$. Phishing links mein random tokens aur hashes hote hain is liye unki entropy high aati hai.

Hissa E: API Endpoints (Lines 75 to 97)

class URLRequest(BaseModel):
    url: str

@app.get("/")
def home():
    return FileResponse(Path(__file__).parent / "index.html")

@app.post("/api/predict")
def predict(req: URLRequest):
    features = extract_features(req.url)
    input_data = pd.DataFrame([features])
    prediction = int(model.predict(input_data)[0])

    if prediction == 1:
        return {"result": "Fake"}
    else:
        return {"result": "Legit Site"}
  • class URLRequest(BaseModel): Frontend se aane wale JSON data ka structure define kiya ke usme url string honi chahiye.
  • @app.get("/"): Jab user browser mein http://127.0.0.1:8000 kholta hai, to yeh function seedha index.html page show kar deta hai.
  • @app.post("/api/predict"): Scan karne ka main endpoint:
    1. URL leta hai aur extract_features se 15 features banata hai.
    2. Un features ko pd.DataFrame mein convert karta hai.
    3. model.predict(...) se prediction leta hai:
      • Agar 1 aaya $\rightarrow$ return {"result": "Fake"}
      • Agar 0 aaya $\rightarrow$ return {"result": "Legit Site"}

Original dataset mein 0 = Phishing tha aur 1 = Legit tha. Data Science conventions mein target (positive class) hamesha 1 hona chahiye us cheez ke liye jisko detect karna ho (yani Phishing = 1). Is liye humne 1 - ClassLabel kiya. Ab:
$\rightarrow$ 1 = Phishing (Fake)
$\rightarrow$ 0 = Legitimate (Legit Site)

gss = GroupShuffleSplit(n_splits=1, test_size=0.20, random_state=42)

Yeh Project Ka Sab Se Bara Technical Weapon Hai (Group Validation):
Agar aap aam train_test_split lagayein to ek hi domain ke do pages (e.g. fakebank.com/a aur fakebank.com/b) train aur test dono mein chale jate hain. Model domain ratta laga leta hai aur fake 99% accuracy dikhata hai (Data Leakage).
GroupShuffleSplit(groups=df["host"]) use karne se poora domain ya train mein rehta hai ya test mein. Is se model unseen websites par test hota hai.

pipeline = Pipeline([

    ("model", LogisticRegression(class_weight="balanced", max_iter=1000, random_state=42))
])

pipeline.fit(X_train, y_train)
score = pipeline.score(X_test, y_test)
print(f"Accuracy: {score * 100:.2f}%")

  • class_weight="balanced": Taake phishing links par zyada dhyan de aur koi fraud link miss na ho (False Negative minimize ho).
  • pipeline.fit(...): Model ne data se patterns seekh liye (Training ho gayi).
  • pipeline.score(...): Test data par accuracy check ki.

async function scanURL(e) {
    e.preventDefault();
    const url = document.getElementById('urlInput').value.trim();
    if (!url) return;

    const response = await fetch('/api/predict', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ url: url })
    });

    const data = await response.json();

    if (data.label === 1) {
        verdictText.textContent = 'Fake';
        verdictText.className = 'verdict verdict-fake';
    } else {
        verdictText.textContent = 'Legit Site';
        verdictText.className = 'verdict verdict-legit';
    }
    resultBox.style.display = 'block';
}

JavaScript Ka Asal Flow:
1. fetch('/api/predict'): Backend ko URL send karta hai.
2. Backend se data.label wapas aata hai.
3. Agar label === 1 ho to text "Fake" aur color Red ho jata hai.
4. Agar label === 0 ho to text "Legit Site" aur color Green ho jata hai.
5. Result box ko screen par display kar deta hai.

5. Top 10 Viva / Defense Questions (Teachers Ke Sawaalat)

Q1: Aapka model URL ko scan karne ke liye internet par open kyun nahi karta?
Jawab: Sir, agar hum submitted URL par request bhejein to malicious scripts run hone ka khatra hota hai, aur network request 3 se 5 seconds leti hai jabke offline lexical extraction sirf microseconds mein complete ho jati hai.
Q2: Shannon Entropy feature ka kya faida hai?
Jawab: Shannon Entropy URL characters ki randomness aur disorder ko measure karti hai. Phishing links mein random tokens aur encoded hashes hote hain jis se unki entropy normal websites se wazeh tor par zyada aati hai.
Q3: Machine Learning mein Data Leakage kya hota hai aur aapne kaise roka?
Jawab: Agar ek hi domain ke URLs train aur test dono mein chale jayein to model domain ko memorize kar leta hai aur fake 99% accuracy dikhata hai. Humne GroupShuffleSplit(groups=df["host"]) lagaya taake poora domain ya train mein rahe ya test mein.
Q4: Dataset ke original labels mein 1 - ClassLabel kyun kiya?
Jawab: Original CSV mein 0 Phishing tha aur 1 Legitimate tha. Data Science conventions mein target hamesha positive class (detect hone wala target) 1 hona chahiye. Is liye humne 1 - ClassLabel kar ke 1 = Phishing standardize kiya.
Q5: StandardScaler Pipeline ke andar lagane ka kya faida hai?
Jawab: URL length ki value 50-100 tak hoti hai jabke IP address ya HTTPS flag sirf 0 ya 1 hote hain. StandardScaler sab features ko 0 mean aur unit variance par normal scale par le aata hai taake Logistic Regression ka decision balance rahe.
Q6: Agar user URL ke shuru mein http:// na likhe to kya code crash karega?
Jawab: Nahi sir, extract_features function ki pehli line check karti hai: agar scheme missing ho to wo automatically http:// prepend kar deti hai taake standard URL parser crash na ho.
Q7: Logistic Regression hi kyun use kiya, Neural Network kyun nahi?
Jawab: Logistic Regression fast hai, low memory leti hai, aur sab se ahem baat ye ke ye black-box nahi hai — iske 15 weights 100% explainable hain jo cyber security mein bohot zaroori hota hai.
Q8: Frontend aur Backend aapas mein kaise baat karte hain?
Jawab: JavaScript ka fetch() method asynchronous POST request ke zariye JSON payload {"url": "..."} backend ke /api/predict endpoint par bhejta hai, aur wahan se return hone wala result screen par update kar deta hai.
Q9: joblib ka kya role hai?
Jawab: train.py mein model train hone ke baad joblib.dump() model ko file mein freeze karta hai, aur main.py mein joblib.load() usay memory mein reload karta hai taake bar bar train na karna pade.
Q10: Kya is project ko chalane ke liye database ki zaroorat hai?
Jawab: Nahi sir, hamara architecture stateless aur real-time hai. Model seedha memory mein chal raha hai is liye database ke baghair ultra-fast prediction karta hai.
